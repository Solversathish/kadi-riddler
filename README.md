# Kadi Riddler

A playful Next.js + Tailwind CSS starter for Kadi Riddler: riddles, Tamil/English kadi jokes, and amazing facts.

## Run locally

Requirements: Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.
